# Kana Reading Drills

Single-file kana reading practice app (`index.html`), with no build step and no dependencies besides Google Fonts. Open it in any browser.

- Sections: Level 1–3, Phrases, Stories, All, Review misses.
- Toggles for romaji, word spacing, translation; tap a word for its gloss.
- Progress is kept in the browser's localStorage.
